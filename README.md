Автоматизация UI тестирования

Описание проекта
Проект представляет собой фреймворк автоматизированного UI тестирования, разработанный с использованием **Python, Selenium WebDriver и Pytest**.
В основе архитектуры используется паттерн **Page Object Model (POM)** для обеспечения масштабируемости и поддержки кода.
Проект направлен на тестирование ключевого функционала e-commerce сайта: поиск товаров и фильтрация результатов.

Технологии
- Python
- Selenium WebDriver
- Pytest
- Page Object Model (POM)

Архитектура проекта
Проект разделён на логические слои:
- `pages/` - Page Object классы (локаторы и методы взаимодействия)
- `tests/` - тестовые сценарии
- `conftest.py` - настройка WebDriver (фикстуры)
- `base_page.py` - базовые методы (click, type, wait)

Реализованные сценарии тестирования
Поиск товаров
- Проверка поиска по нескольким категориям товаров
- Использование параметризации Pytest
Фильтрация товаров
- Применение фильтра по категории (например, Gender - Men)
- Проверка обновления результатов после применения фильтра
Параметризованные тесты
Тестирование поиска для нескольких значений:
- shoes
- dress
- jacket
- t-shirt
- jeans
